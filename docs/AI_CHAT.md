# AI แชทของเว็บ (น้อง Nova) — รู้อะไร จากที่ไหน

ปุ่มแชทมุมจอทุกหน้า (`components/ai-chat-widget`) และช่อง "ถามหนูได้เลย" ของน้อง Nova บนหน้าแรกจักรวาล 3D
(`partials/universe/guide` → `resources/js/universe/ui/Chat.js`) ส่งคำถามไปที่ `POST /ai-chat`
(`PublicChatController`) ตัวเดียวกัน ทุกคำถาม `ChatPrompt` ประกอบ system prompt ใหม่จากเว็บจริง ณ ตอนนั้น
**ไม่มีรายชื่อหน้า ลิงก์ ราคา หรือข้อมูลบริษัทเขียนตายตัวในโค้ด** — เว็บเปลี่ยน AI เปลี่ยนตาม

---

## 1. แผนที่ไฟล์ (`app/Services/AiChat/`)

| ไฟล์ | ตอบคำถามว่า | มาจาก |
|---|---|---|
| `VisitorContext` | คุยกับใคร ฐานะอะไร | `auth()->user()` เท่านั้น — ชื่อ, บทบาท (ลูกค้า/แอดมิน/Super Admin + roles), แพ็กเกจเช่า, Affiliate; ออเดอร์/License/Wallet/ตั๋ว เฉพาะเมื่อเปิดสวิตช์ |
| `CurrentPage` | เปิดหน้าไหนอยู่ บนจอมีอะไร | จับ path กับ router → ประเภทหน้า, ข้อมูลจริงจาก DB ของหน้านั้น (สินค้า/บริการ/ตะกร้า/ออเดอร์ของเขา), เนื้อหาจาก `SiteIndex` หรือ snapshot จากเบราว์เซอร์ |
| `SiteMap` | เว็บมีหน้าอะไรบ้าง | ตาราง route จริง (GET, มีชื่อ, ไม่มีพารามิเตอร์) — หน้าสาธารณะ / หน้าสมาชิก / หน้าแอดมิน (บอกเฉพาะแอดมิน) |
| `SiteIndex` | แต่ละหน้าเขียนว่าอะไร | render ทุกหน้าสาธารณะภายในโปรเซส อ่านด้วย `PageText` เก็บที่ `storage/app/ai-chat/site-index.json` |
| `CatalogFacts` | ขายอะไร ราคาเท่าไหร่ | `config/licenses.php` (LicensePlans), `Pricing::saleDiscount()`, ตาราง products/services/quotation/rental |
| `KnowledgeVersion` | ข้อมูลสินค้าเก่าไหม | เลขเวอร์ชันที่ขยับทุกครั้งที่แอดมิน save/delete สินค้า บริการ แพ็กเกจ แบนเนอร์ คูปอง (`AppServiceProvider`) |
| `Keywords` | คำถามนี้พูดถึงอะไร | ตัดคำไทยด้วย ICU (intl) แยกไทย/อังกฤษ ตัดคำฟุ่มเฟือย |

ส่วน snapshot หน้าจอฝั่งเบราว์เซอร์: `resources/views/partials/ai-chat-page.blade.php`
(`window.xmanPageSnapshot()` + `window.xmanChatClaimHistory()`) ใช้ร่วมทั้งสองหน้าแชท

## 2. ความสดของข้อมูล

| ข้อมูล | อัปเดตเมื่อ |
|---|---|
| สินค้า/บริการ/แพ็กเกจ/แบนเนอร์/คูปอง | ทันทีที่แอดมิน save (KnowledgeVersion) · update แบบ bulk ที่ไม่ยิง event → ภายใน 1 ชม. |
| ราคา License ของแอป, โปรโมชั่น 50/70% | deploy (อ่านจาก config / `Pricing` ที่หน้าเว็บใช้) |
| รายชื่อหน้า (SiteMap) | ทันทีที่ deploy — อ่านจาก router ทุกคำถาม |
| เนื้อหาหน้า (SiteIndex) | `ai-chat:index --if-stale` ทุก 10 นาทีใน scheduler: อ่านใหม่เมื่อ VERSION หรือรายการหน้าเปลี่ยน หรือเก่ากว่า 6 ชม. |
| ข้อมูลติดต่อ, ชื่อบอท, คำสั่งเพิ่มเติม | ทันที (settings) |

สั่งอ่านเว็บใหม่เอง: `php artisan ai-chat:index`

## 3. หน้าที่เปิดอยู่มาก่อนผลค้นหา

บทเรียนจาก prod วันแรก: ลูกค้าอยู่หน้าราคา Tping ถาม "หน้านี้คืออะไร แพ็กเกจไหนคุ้มสุด" แล้วน้องตอบเรื่องแพ็กเกจเช่า
เพราะการค้นคำ "แพ็กเกจ" ดึงรายการอื่นมาวางพร้อมป้าย "ใช้ข้อมูลนี้ตอบ" กติกาตอนนี้:

- คำถามที่ชี้หน้า (`นี้` `นี่` `this page` `this one` `here`) → ไม่ค้นอะไรเพิ่มเลย ตอบจากหน้าที่เปิดอยู่
- นอกนั้นค้นด้วยคำที่เจาะจงเท่านั้น: ตัดคำที่อยู่เกินหนึ่งในสามของหน้าเว็บทิ้ง (`SiteIndex::specific`) — "ราคา" "หน้า" ไม่ชี้ไปไหน
- ค้นใน DB เฉพาะ **ชื่อ** (name, name_th, slug, บรรทัดสรุปสินค้า) ไม่ค้นคำโฆษณา/รายละเอียดยาว
- หน้าที่เกี่ยวข้องต้องมีคำนั้นใน title/หัวข้อ (มีแค่ในเนื้อความไม่นับ) และหน้าในหมวดเดียวกับหน้าที่เปิดอยู่ได้ก่อน
- ท้าย prompt ย้ำว่าคำถามที่ไม่เอ่ยชื่อสิ่งอื่น หมายถึงสิ่งบนหน้านี้ พร้อมชื่อเรื่องของหน้า
- ตัดคำไทย: คำเฉพาะทางที่ ICU หั่นผิด (แพ็กเกจ ติดตั้ง ตลอดชีพ โปรโมชั่น …) เก็บทั้งคำใน `Keywords::WHOLE_WORDS`

## 4. ความเป็นส่วนตัว

- ข้อมูลบัญชี (ออเดอร์ License Wallet ตั๋ว และข้อมูลในหน้าออเดอร์/License ที่เปิดอยู่) ใส่เฉพาะเมื่อเปิด
  **แอดมิน → ตั้งค่า AI → ประวัติการสั่งซื้อ / ข้อมูลบัญชี** (`ai_use_order_history`) — ชื่อและฐานะรู้เสมอ
- ไม่มีวันใส่ตัว License Key รหัสผ่าน หรือ token · ข้อมูลของสมาชิกอื่นอ่านด้วย `user_id` ของผู้ถามเสมอ
- snapshot ของหน้าที่ต้องล็อกอิน: ใช้แค่หัวข้อ ไม่ส่งเนื้อหาบนจอต่อให้ผู้ให้บริการ AI
- ข้อความจากเบราว์เซอร์ถูกตัดความยาว ลบรูปแบบคีย์/token/อีเมล/เบอร์โทร และห้ามขึ้นต้นด้วย `===`
- ประวัติแชทใน sessionStorage ถูกล้างเมื่อสมาชิกออกจากระบบหรือมีคนอื่นล็อกอินในแท็บเดิม

## 5. เพิ่ม/แก้หน้า — ต้องทำอะไร

- **หน้าสาธารณะใหม่**: ไม่ต้องทำอะไร — route ใหม่ขึ้นในแผนที่ทันที เนื้อหาถูกอ่านภายใน 10 นาทีหลัง deploy
  ถ้าเป็น endpoint ไม่ใช่หน้า (ไฟล์, JSON, redirect) ให้ใส่ throttle หรือคำว่า download ใน URI หรือเพิ่มใน `SiteMap::NOT_A_PAGE`
- **หน้าสมาชิกใหม่**: ขึ้นในแผนที่เองด้วย path — ใส่ชื่อไทยใน `SiteMap::MEMBER_LABELS` ให้ AI เรียกถูก
- **หน้าที่ควรมีข้อมูลจาก DB เฉพาะ** (เช่น record ของลูกค้า): เพิ่มกรณีใน `CurrentPage::facts()` — อ่านด้วย `user_id` เสมอ
- **ส่วนของหน้าที่ไม่ควรให้ AI อ่าน**: ใส่ `data-ai-ignore` บน element นั้น
- **เปลี่ยนโปรโมชั่นบริการ**: แก้ที่ `Pricing::saleDiscount()` ที่เดียว (หน้าเว็บ ใบเสนอราคา และ AI ใช้ร่วมกัน)

## 6. กับดัก

- `InputSanitizerService::sanitizeForPrompt()` ตัดความยาวแบบ byte — ตัดกลางตัวอักษรไทยแล้วข้อความหายทั้งก้อน
  ข้อความภาษาไทยยาวๆ ใช้ `CurrentPage::untrusted()` แทน
- UA ของตัวอ่านเว็บห้ามมีคำว่า bot/crawler/spider — `UniverseHome` จะส่งหน้าแรกแบบ classic ให้แทนหน้าจักรวาล
- ป้ายสองภาษา (`<x-bi>`) ไม่มีช่องว่างระหว่างไทย/อังกฤษใน HTML — `PageText` เติม " / " ให้เอง
- `route:cache` บน prod ตั้งชื่อ route ที่ไม่มีชื่อเป็น `generated::…` — `SiteMap` ถือว่ายังไม่มีชื่อ (เป็น redirect/JSON ไม่ใช่หน้า)
- รายละเอียดบริการบางรายการเก็บเป็น JSON ของ page builder — `CatalogFacts::plain()` แปลงเป็นข้อความก่อนส่ง
