EDL Client (bkerler)Qualcomm EDL/Firehose tool - Requires Python

Communicate with Qualcomm devices in EDL (Emergency Download) mode. Read/write partitions, unlock bootloader.

How to enter EDL mode:
• Turn off device + hold Vol- and plug USB
• Via ADB: adb reboot edl
• Hardware test point (device specific)
